# Licensing

Seed Protocol contains different kinds of work. The applicable license follows the artifact, not the file extension alone.

## Software — Apache License 2.0

Software, executable tooling, tests, configuration intended to be executed, and code examples substantial enough to be reused as software are licensed under the [Apache License 2.0](LICENSES/Apache-2.0.txt).

This currently includes:

- `tools/`;
- `tests/`;
- executable portions of templates;
- future software unless it declares another license.

SPDX identifier: `Apache-2.0`

## Knowledge and media — Creative Commons Attribution 4.0

Prose, documentation, specifications, manifests as descriptive data, diagrams, research records, templates as documents, and media are licensed under the [Creative Commons Attribution 4.0 International license](LICENSES/CC-BY-4.0.txt), unless an artifact declares another license.

This currently includes:

- root Markdown and manifest documents;
- `context/`, `decisions/`, `challenges/`, `experiments/`, `history/`, `research/`, and `spec/`;
- explanatory portions of `templates/`;
- diagrams and other media.

SPDX identifier: `CC-BY-4.0`

Suggested attribution:

> “Seed Protocol,” Seed S-0000 contributors, licensed under CC BY 4.0, with a link to the source and an indication of changes.

Git history is the primary contributor-attribution record. Individual artifacts may include more specific provenance.

## Mixed files and exceptions

When a file contains both documentation and executable code, reusable code is offered under Apache-2.0 and the surrounding explanatory work under CC-BY-4.0. If that distinction is impractical, open an issue so the artifact can declare one clear license.

Third-party material remains under its original terms and must be identified near the artifact. No repository license overrides third-party rights, privacy obligations, trademarks, patents not covered by Apache-2.0, or permissions the contributor did not possess.

## Contributions

Unless explicitly agreed otherwise before acceptance, contributions are licensed under the license applicable to the area they modify. Contributors retain copyright and provide the permissions described by that license.

This mapping is an R&D decision, not legal advice. It should receive legal review before institutional adoption, high-value commercialization, or the acceptance of materially complex third-party assets.
