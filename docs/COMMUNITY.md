# Community surfaces

Seed Protocol uses GitHub’s existing collaboration tools as adapters. They are not protocol requirements.

## Begin in one of three places

- [Welcome and first impressions](https://github.com/JjAaKeEe/seed-protocol/discussions/1)
- [Attack the Seed](https://github.com/JjAaKeEe/seed-protocol/discussions/2)
- [Match your knowledge to a Quest](https://github.com/JjAaKeEe/seed-protocol/discussions/3)

## Discussion category map

| Category | Use |
|---|---|
| Announcements | Maintainer updates and major state changes |
| General | Welcome, early exploration, expertise offers, and open-ended attacks |
| Ideas | Possibilities not ready to become a tracked object |
| Q&A | Answerable questions about the protocol or contribution paths |
| Show and tell | Reference Seeds, experiments, tools, or derivatives people have made |
| Polls | Limited preference checks; never a substitute for evidence or authority |

Use an Issue when work is bounded enough to track. Use a Discussion while the shape of the question is still emerging. Use a pull request when a concrete repository change is ready for review.

## Community principle

Activity is not the objective. Useful uncertainty reduced, errors caught, knowledge transferred, and participants connected to meaningful work are better outcomes than posting frequency or time spent.
