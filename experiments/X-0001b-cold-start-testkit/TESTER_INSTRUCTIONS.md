# Tester Instructions (give receivers ONLY this page plus their files)
DRAFT v0.1. Do not add hints, definitions, or examples of good answers.

## For a human
You will get a small set of files or one page about an idea. You have never seen it. You may not ask the author questions during the test.
1. Start a 15-minute timer, then open the files.
2. Read only what you were given. Do not search the web.
3. Answer the 8 questions below in writing, in your own words.
4. If an answer is not supported by the files, write "NOT IN FILES" for it. Guessing is allowed but label it "GUESS".
5. When time ends, stop. Hand the answers back as they are. Do not tidy them.
Also write: your first name, whether you had seen the idea before (yes/no), and how many minutes you used.

## For a fresh AI context
Use a new session with no memory, no tools, no browsing, and no prior chat. Paste only: this page, then the files. Run once. Do not retry or edit the prompt. Save the complete response unedited. Record: model name and version, product/environment, date and time, temperature if known, exact prompt, and file versions.

## Questions
1. What is this, in two sentences?
2. Why does it matter, and to whom?
3. List what is known, what is assumed, and what is unknown.
4. What observation would prove it wrong or make you drop it?
5. What limits (law, safety, budget, time, physical) apply?
6. What are you NOT allowed to do with this without asking, and who do you ask?
7. What is the single next action someone could start today?
8. Name one thing that is weak or missing.

## For the proctor / Cord
- Give the receiver exactly the files for one arm of one idea. Do not say which arm it is, or that another arm exists.
- Do not answer questions about content. If asked, say "Answer from the files only."
- Save raw outputs as received to `raw/<receiver_id>.txt` (create the folder when running). Never edit raw files; corrections go in grader notes.
- Record start and end time.
